What is hoisting in javascript ?
Hoisting is a JavaScript mechanism where variable, function, and class declarations are conceptually moved to the top of their containing scope during the compilation phase, before the code actually executes. This means you can reference or use functions and variables before the lines of code where they are formally defined.
