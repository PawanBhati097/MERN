How we can access any HTML element in our JS?
To access HTMl in JS we have three methods:
--> getElementById()
--> getElementByClassName()
--> getElementByTagName()

--> querySelector(.classname/#idname/tagname) : It only access one element 
--> querySelectorAll(.classname/#idname/tagname) : It makes the node list

How we can edit the text of particular element?
--> innerText
--> innerHTML
