DOM MANIPULATION - COMPLETE NOTES
1. ACCESSING ELEMENTS
javascript
// By ID (returns single element)
document.getElementById("idName")

// By Class (returns HTML Collection - all elements with class)
document.getElementsByClassName("className")

// By Tag (returns HTML Collection - all elements with tag)
document.getElementsByTagName("tagName")

// Modern ways (recommended)
document.querySelector(".class")      // Returns FIRST match
document.querySelector("#id")         // Returns FIRST match
document.querySelector("tag")         // Returns FIRST match

document.querySelectorAll(".class")   // Returns ALL matches (NodeList)
document.querySelectorAll("#id")      // Returns ALL matches (NodeList)
document.querySelectorAll("tag")      // Returns ALL matches (NodeList)
2. CHANGING TEXT
javascript
element.innerText = "New text"        // Changes visible text only
element.innerHTML = "<b>Bold</b>"     // Changes HTML content (can include tags)
3. ADDING STYLES
javascript
element.style.color = "red"           // Changes text color
element.style.fontSize = "50px"       // Changes font size
element.style.backgroundColor = "yellow" // Changes background color
element.style.padding = "20px"        // Adds padding
Note: Use camelCase for CSS properties

background-color → backgroundColor

font-size → fontSize

margin-top → marginTop

4. CREATING ELEMENTS
javascript
document.createElement("h1")          // Creates <h1></h1>
document.createElement("p")           // Creates <p></p>
document.createElement("div")         // Creates <div></div>
5. ADDING ELEMENTS TO PAGE
javascript
parent.append(child)                  // Adds at END inside parent
parent.prepend(child)                 // Adds at START inside parent

// Insert at specific positions
element.insertAdjacentElement("beforebegin", newElement)  // Before element
element.insertAdjacentElement("afterbegin", newElement)   // Inside, at top
element.insertAdjacentElement("beforeend", newElement)    // Inside, at bottom
element.insertAdjacentElement("afterend", newElement)     // After element
Visual:

text
[beforebegin]  → Before the element
  <element>
    [afterbegin] → Inside at top
    Content
    [beforeend]  → Inside at bottom
  </element>
[afterend]     → After the element
6. EVENT LISTENERS
javascript
element.addEventListener("click", function() {
    // Code runs when clicked
})

// Common events
click          // When element is clicked
dblclick       // When double clicked
submit         // When form is submitted
change         // When input value changes
mouseover      // When mouse hovers over
mouseout       // When mouse leaves
keydown        // When key is pressed
keyup          // When key is released
7. WORKING WITH INPUT
javascript
input.value                           // Gets what user typed
input.value = "Hello"                 // Sets value

// Listen for changes
input.addEventListener("input", function(e) {
    console.log(e.target.value)       // Shows on every keystroke
})

input.addEventListener("change", function(e) {
    console.log(e.target.value)       // Shows when focus lost
})
8. FORM HANDLING
javascript
form.addEventListener("submit", function(e) {
    e.preventDefault()                // Stops page refresh
    
    let data = {
        name: inputName.value,
        email: inputEmail.value
    }
    console.log(data)                 // {name: "John", email: "john@email.com"}
})
Note: Form automatically refreshes page. Use preventDefault() to stop it.

9. classList METHODS
javascript
element.classList.add("className")       // Add a class
element.classList.remove("className")    // Remove a class
element.classList.contains("className")  // Check if exists (true/false)
element.classList.toggle("className")    // Add if missing, remove if present
10. GETTER & SETTER
javascript
element.getAttribute("id")               // Get attribute value
element.setAttribute("class", "newClass") // Set attribute value

EXAMPLE: PUTTING IT ALL TOGETHER
html
<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1 id="title">Hello</h1>
    <p class="para">First paragraph</p>
    <p class="para">Second paragraph</p>
    <input type="text" id="nameInput" placeholder="Enter name">
    <button id="btn">Submit</button>

    <script>
        // Access elements
        let title = document.getElementById("title")
        let paras = document.querySelectorAll(".para")
        let input = document.getElementById("nameInput")
        let button = document.getElementById("btn")
        
        // Change content
        title.innerText = "New Title"
        paras.forEach(p => p.style.color = "blue")
        
        // Event listener
        button.addEventListener("click", function() {
            alert("Hello, " + input.value)
        })
    </script>
</body>
</html>
KEY POINTS TO REMEMBER
ID must be unique → use getElementById()

Class can be multiple → use getElementsByClassName() or querySelectorAll()

querySelector() returns FIRST match only

querySelectorAll() returns ALL matches

Use preventDefault() to stop form refresh

CSS properties in JS use camelCase

append() adds at end, prepend() adds at start

innerText for text only, innerHTML for HTML content
