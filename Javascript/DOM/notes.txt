Feature     	    HTML Collection	                            NodeList
Returned by	        getElementsBy...()	                        querySelectorAll()
Live/Dynamic	    ✅ Live (updates automatically)             ❌ Static (doesn't update)
Array methods	    ❌ No (forEach works in some browsers)	   ✅ Yes (forEach, etc.)
Index access	    ✅ Yes (collection[index])	               ✅ Yes (list[index])
Length property	    ✅ Yes	                                   ✅ Yes  
Contains	        Only element nodes	                        All node types (text, comments, etc.
