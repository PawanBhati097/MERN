What is Virtual DOM?
Virtual DOM is a copy of real DOM where it uses reconcilation and diffing algorthim to create the changes on our pages.
Reconcilation is a react process that compares two virtual dom trees to find out the minimal changes that it can update the real browser DOM.
Diffing algorthim is a react algorthim that compares the old & new virtual dom to update the real dom , here the dom is not created on each update it only updates the changes in the dom.
